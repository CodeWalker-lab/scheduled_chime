＊このソフトウェアについて
パソコンで簡易的にチャイムをシミュレートします。

・受験勉強に
学校のチャイムとあわせれば、日曜日もいつもどおりの時間で動けます。

・多機能タイマーとして
何回もタイマーを鳴らす必要があるときにも

・チャイムの故障時に
パソコンの音声出力端子と放送設備の入力端子をつなげば、チャイムとしても使えます。

・時計を見るのが面倒なときに
好きなタイミングでならせるので、予定の管理にも使えるかもしれません。

＊使用方法

１）上部にある[...]ボタンを押して、音声ファイルを選択してください。
２）時刻を設定し、鳴らしたい時刻の設定にチェックを入れてください。
３）[開始]ボタンを押すと、タイマーが動き出します。

※チャイム メニューの 自動的に開始 にチェックを入れることで、次回アプリケーションを起動する際に今回の設定で自動的に開始することができます。

＊動作環境
Microsoft dotNetFramework 2.0 以上
