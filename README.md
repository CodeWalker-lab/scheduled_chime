# 定刻チャイム（スクールチャイム）

* 開発背景：
講師が休み時間を忘れ、10分、20分と授業を続けるため、作ってあげました。

<img width="277" height="296" alt="image" src="https://github.com/user-attachments/assets/635779a6-be01-4d7b-865d-5f2724836388" />


* 開発環境：
  Visual Studio Code
  
* 言語：
  Python

* 利用方法：
  - ①[アプリファイル](https://github.com/CodeWalker-lab/scheduled_chime/blob/main/scheduled_chime.exe)（.EXE）とサンプル音源ファイル（.WAV）をWindows PCにコピー
  - ②アプリファイルを実行し、デフォルト時間から定刻に変更する。音源ファイルを選択して開始ボタンを押す。
